# 🧭 CLIQuest Curriculum

> **Learn Linux. One Quest at a Time.**

## Overview

CLIQuest is not a Linux tutorial.

It is an interactive learning adventure designed to help beginners become confident Linux users through storytelling, demonstrations, exploration, and hands-on practice.

Every command should solve a real problem.

Every quest should build confidence.

Every Explorer should feel safe to learn, make mistakes, and ask questions.

---

# 🎯 Learning Objectives

By completing CLIQuest, every Explorer should be able to:

- Understand fundamental Linux concepts.
- Navigate the Linux terminal confidently.
- Understand what Linux commands mean instead of memorizing them.
- Solve real-world Linux problems.
- Develop confidence through practice and repetition.
- Think like a Linux user instead of simply remembering commands.

---

# 📚 CLIQuest Teaching Standard

Every quest follows the same teaching structure.

The objective is not simply to explain commands.

The objective is to create understanding.

---

## 🌍 1. Story

Every lesson begins with a story.

Stories create curiosity and provide context before introducing a command.

Example:

> You've just logged into a Linux server.
>
> Your mentor asks,
>
> "Explorer... where are you?"

---

## 🎯 2. Mission

Every quest gives the Explorer a mission.

Examples:

- Find out who you are.
- Discover where you are.
- Look around your current location.
- Create your first workspace.

---

## 📖 3. Command Introduction

Every command is introduced using the same structure.

Example:

**Command**

pwd

**Full Meaning**

Print Working Directory

**Simple Explanation**

Show me the folder you're currently in.

**Why It Matters**

Before creating, moving, copying, or deleting files, you should always know where you are.

---

## 🎭 4. Demonstration

Show the command before fully explaining it.

Allow the Explorer to become curious.

Learning begins with observation.

---

## 🤔 5. Let the Explorer Guess

Before explaining the command, ask the Explorer what they think it does.

There are no embarrassing answers.

CLIQuest encourages curiosity.

Examples:

- "What do you think this command does?"
- "Why do you think Linux named it this?"

---

## 💡 6. Explanation

Explain the command using simple language.

Avoid unnecessary technical words.

Whenever technical terms are necessary, explain them immediately.

Examples:

Directory = Folder

Path = The location of a file or folder.

Root = The highest level of the Linux file system.

---

## 🖥️ 7. Practice

Every lesson requires the Explorer to use the real Linux terminal.

Learning happens through doing.

---

## 🎉 8. Celebration

Celebrate every completed quest.

Recognize effort.

Reward progress.

Encourage curiosity.

---

## 🧠 9. Reflection

Every lesson ends with reflection.

Examples:

- What surprised you today?
- What did you learn?
- When would you use this command?
- What would you like to explore next?

Reflection transforms experience into understanding.

---

# 🧭 Quest 1 — Who Am I?

### Story

You've just logged into a Linux machine.

Before doing anything else, you want to know who Linux thinks you are.

### Mission

Discover your current user account.

### Command

whoami

### Full Meaning

Who Am I

### Simple Explanation

Show the username of the person currently using Linux.

### Why It Matters

Knowing your current user helps you understand your permissions and confirms which account you're using.

### Learning Objective

Understand user identity in Linux.
