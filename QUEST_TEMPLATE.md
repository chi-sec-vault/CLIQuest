# 🧭 CLIQuest Quest Template

This document defines the structure every CLIQuest quest should follow.

Every quest should teach:
- A Linux concept
- A practical command
- A reason why the command matters
- A hands-on experience

---

# Quest Identity

## Quest Number:
Example: Quest 2

## Quest Title:
Example: WHERE AM I?

## Linux Command:
Example: pwd

## Full Meaning:
Example: Print Working Directory

## Category:
Example:
- Navigation
- File Management
- System Information
- Networking
- Security

## Difficulty:
Example:
- Beginner
- Intermediate
- Advanced

---

# 🧙 Mentor Introduction

The Mentor introduces the situation.

Goals:
- Create curiosity
- Explain why the Explorer needs this skill
- Connect the command to a real-world problem

Example:

"Explorer, before you begin your journey,
you must understand where you are standing."

---

# 📜 Story

Describe the scenario.

The Explorer should feel like they are inside an adventure.

Questions to answer:

- What problem exists?
- Why does this command solve it?
- What happens if the Explorer does not know this?

---

# 🎯 Mission

Clearly define what the Explorer must accomplish.

Example:

"Discover your current location inside the Linux filesystem."

---

# 📖 Command Teaching

## Command:



## Full Meaning:

Example:

pwd

- Display information

# 💡 Simple Explanation

Explain what the command does in beginner-friendly language.

Avoid:
- Technical jargon
- Unnecessary complexity

# ⚔️ Practice Challenge

The Explorer performs the command.

Requirements:

- User types the command
- CLIQuest checks the answer
- Mentor responds

# 🏆 Completion

Include:

- XP reward
