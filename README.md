# 🧭 CLIQuest

> Learn Linux. One Quest at a Time.

CLIQuest is an open-source terminal companion designed to help beginners learn Linux and cybersecurity through interactive quests, friendly guidance, and hands-on practice.

## 🌟 Our Mission

CLIQuest exists to make learning Linux feel exciting, safe, and rewarding—one quest at a time.

We believe beginners should never feel judged for forgetting commands or asking questions.

## 🚀 Current Features

- 👋 Personalized welcome experience
- 💾 Remembers returning users
- 🧠 Beginner-friendly interactions
